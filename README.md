# 极简番茄钟 V0.1

手机优先的 React + TypeScript + Vite 极简倒计时工具。

## 运行

```bash
npm install
npm run dev
```

## 计时说明

计时器以“目标结束时间 - 当前时间”计算剩余秒数，定时器只负责刷新显示，因此不会因为 `setInterval` 的调度误差持续累减而明显漂移。选择快捷时长或提交自定义分钟数只会设置时间，必须点击“开始”才会启动。

浏览器标签页进入后台、系统节流，尤其是 iPhone 锁屏时，网页 JavaScript 的执行可能被暂停或延迟；Web Audio API 也需要用户手势并不能保证在锁屏状态下播放提示音。因此 V0.1 不宣称锁屏后台下可靠计时或可靠响铃。前台使用时，完成只触发一次短促提示音。
